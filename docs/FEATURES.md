## 1. Architectural Overview
Continuum replaces vendor-locked ecosystem hooks (such as Apple Continuity) with an instruction-set-agnostic presence, state, and hardware virtualization backplane. It operates across `x86_64`, `ARM64`, `RISC-V`, and `wasm32` environments, bridging bare-metal desktop operating systems (Ubuntu Linux, Windows, macOS), mobile sandboxes (Android, iOS/iPadOS), containerized guest VMs (ChromeOS Crostini / `CrosVM` / `ARCVM`), and cloud-streamed Virtual Application Delivery (VAD / Cameyo) viewports.

Every module below multiplexes over a single authenticated `QUIC` / `WebRTC` peer-to-peer transport channel secured by an IETF RFC 9420 Messaging Layer Security (`MLS`) ratchet, selectable between Branch A (Zero-Knowledge OAuth 2.1) and Branch B (Trustless W3C `DID` + `libp2p` + L2 Smart Contract Vault).
